# Calendarsver2 — ปฏิทินตารางงาน (ตัวใหม่)

ปฏิทินตารางงานของพนักงาน แยกสาขาได้ หัวข้อเพิ่มเองได้ ข้อความถึงทีมงาน 6 ภาษา
(ไทย / อังกฤษ / พม่า / ลาว / เขมร / เวียดนาม)

- `index.html` หน้าปฏิทิน (เปิดผ่าน GitHub Pages)
- `supabase/` ฐานข้อมูลและโค้ดฝั่ง Supabase พร้อมคู่มือตั้งค่า: [supabase/README.md](supabase/README.md)

ตัวเก่า (repo `CalendarsCST`) ยังใช้งานจริงอยู่ ตัวนี้แยกไว้ทดลองก่อน ไม่กระทบตัวเก่าและระบบตอกบัตร (`work`)
ข้อมูลอยู่ใน Supabase project ของระบบพนักงาน ซึ่งระบบตอกบัตรตัวใหม่ (`Clockinclockout-rosjana`) จะใช้ร่วมกัน
