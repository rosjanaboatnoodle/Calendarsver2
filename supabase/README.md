# Supabase ของระบบพนักงาน

Supabase project นี้แยกจาก project ของแอปเช็คสต็อก ตอนนี้ใช้กับปฏิทินตารางงาน (แยกสาขาได้ หัวข้อเพิ่มเองได้ 6 ภาษา) ระบบตอกบัตรจะเพิ่มเข้ามาใน project นี้ทีหลัง และใช้ตาราง `staff` กับ `translations` ร่วมกัน

## ตั้งค่าครั้งแรก

1. สร้าง project ใหม่ที่ supabase.com (ตั้ง Region เป็น Singapore จะเร็วสุด)
2. SQL Editor → วางไฟล์ `migrations/0001_schedule.sql` ทั้งไฟล์ → Run
3. Edge Functions → Create function ชื่อ `api` → วางไฟล์ `functions/api/index.ts` ทั้งไฟล์ → Deploy
4. Edge Functions → Secrets → เพิ่ม 3 ตัว
   - `SCHEDULE_SHEET_ID` = `1OCM5dVZYTRedlqWmVEooy7_fruLN_z65RMMnnPAjhKE` (ชีท "ระบบคิดเงินเดือนพนักงาน")
   - `GOOGLE_SERVICE_ACCOUNT_JSON` = เนื้อหาไฟล์ JSON ของ Google service account ทั้งไฟล์
     (ใช้ตัวเดียวกับที่ project แอปเช็คสต็อกใช้ได้)
   - `GEMINI_API_KEY` = key ของ Gemini สำหรับแปลภาษา (ใช้ตัวเดียวกับแอปเช็คสต็อกได้ หรือสร้างใหม่ที่ Google AI Studio)
5. เปิดชีท "ระบบคิดเงินเดือนพนักงาน" → Share → ใส่อีเมล `client_email` จากไฟล์ JSON ข้อ 4 → สิทธิ์ Editor
6. ดึงข้อมูลเดิมจากชีทเข้ามาเป็นสาขาแรก (ใช้รหัสแอดมินปฏิทินตัวเดิม) แทน `PROJECT_REF`, `KEY`, `รหัสแอดมินปฏิทิน` และตั้งชื่อสาขาตามต้องการ:

   ```bash
   curl -X POST https://PROJECT_REF.supabase.co/functions/v1/api -H "Content-Type: application/json" -H "apikey: KEY" -H "Authorization: Bearer KEY" -d '{"action":"import_schedule_from_sheet","admin_pin":"รหัสแอดมินปฏิทิน","branch_id":"main","branch_name":"รสจนา สาขาหลัก"}'
   ```

   ถ้าได้ `{"ok":true,...}` คือเรียบร้อย ระบบจะ
   - สร้างสาขา `main` และตั้งให้สาขานี้ซิงก์กับแท็บ SCHEDULE ในชีท
   - ดึงวันในปฏิทิน ข้อความแจ้งเตือน (ไทย/พม่า) และรายชื่อคนเวร (Kla / Bank / Maylin / Hom) เข้ามา
     ข้อความพม่าที่เขียนไว้ในชีทถือว่า "แก้เอง" AI จะไม่ทับ
   - ตั้งรหัสแอดมินกลาง = รหัสเดิมของปฏิทิน

   กดซ้ำได้ไม่เสียหาย
7. ใน `index.html` ใส่ `PROJECT_REF` กับ `SUPABASE_KEY` (Project Settings → API → publishable key)
8. เปิดหน้าปฏิทิน → ⚙️ → ภาษาบนหน้าเว็บ → **🌐 แปลส่วนที่ยังไม่แปล** (แปลปุ่มและข้อความของทุกหัวข้อทีเดียว)

## หัวข้อ และข้อความถึงทีมงาน

⚙️ → หัวข้อในปฏิทิน

- **+ เพิ่มหัวข้อ**: ชื่อ, คำสั้นบนปฏิทิน, สี, ประเภท
  - แบบติ๊ก = มี/ไม่มีในวันนั้น (เช่น วันหยุด)
  - แบบเลือกคน = เลือกพนักงาน 1 คน (เช่น ตารางเวรใหม่) ใช้ `{name}` ในข้อความแทนชื่อคน
- **🌐 แปลด้วย AI** → เติม 5 ภาษาในช่องด้านล่าง → เช็ค/แก้ → **บันทึกหัวข้อ**
- ช่องที่แก้เองจะเป็นสีส้ม กดแปลด้วย AI ซ้ำก็จะไม่ทับช่องนั้น
- ลบหัวข้อ = ซ่อน ข้อมูลเก่ายังอยู่

พนักงานเลือกภาษามุมขวาบน กดวันไหนก็เห็นข้อความของวันนั้นเป็นภาษาตัวเอง

## เพิ่มสาขา / พนักงาน

กดปุ่ม ⚙️ บนหน้าปฏิทิน → ใส่รหัสแอดมินกลาง

- **+ เพิ่มสาขา**: ใส่ชื่อสาขา และรหัสสาขาภาษาอังกฤษ (ใช้ในลิงก์ เช่น `?branch=branch2`)
- **รหัสแอดมินของสาขา** (ไม่บังคับ): ให้หัวหน้าสาขาแก้ปฏิทินได้แค่สาขาตัวเอง ส่วนรหัสกลางแก้ได้ทุกสาขา
- **พนักงาน**: ชื่อ (ใช้ในข้อความแจ้งเตือน) / ชื่อเต็ม (แสดงในตัวเลือก) / ชื่อสั้น (แสดงบนปฏิทิน)
  คนที่ลบออกจากรายชื่อ ข้อมูลเก่าในปฏิทินจะยังอยู่
- ส่งลิงก์ของแต่ละสาขาให้พนักงานสาขานั้น หน้าเว็บจะเปิดสาขานั้นให้เลย

## คำแปล (ตาราง `translations`)

ทุกข้อความ 1 แถว มีช่อง th / en / my / lo / km / vi ใช้ร่วมกันทุกระบบใน project นี้
- `ui.cal.*` ข้อความบนหน้าปฏิทิน (ต้นฉบับไทยอยู่ใน `UI_TH` ใน `index.html`)
- `topic.<id>.name / short / message` ข้อความของหัวข้อ
- ช่อง `edited` = ภาษาที่คนแก้เอง AI จะไม่ทับ (ถ้าแก้ต้นฉบับภาษาไทย ระบบจะแปลใหม่ทั้งหมด)
- ระบบตอกบัตรจะใช้ `ui.clock.*` ในตารางเดียวกัน

หน้าเว็บโหลดคำแปลของภาษาที่เลือกครั้งเดียวตอนเปิด และเก็บไว้ในเครื่อง AI ทำงานเฉพาะตอนแอดมินกดแปล

## Actions ใน `api`

| action | ใครเรียกได้ | ทำอะไร |
| --- | --- | --- |
| `bootstrap` | ทุกคน | ตอนเปิดหน้า: สาขา + พนักงาน + หัวข้อ + คำแปลของภาษาที่เลือก (`lang`) |
| `schedule_month` | ทุกคน | รายการทั้งเดือนของสาขา (`branch`, `month`: `2026-11`) |
| `save_schedule_day` | รหัสกลาง หรือรหัสของสาขานั้น | บันทึกหัวข้อของวัน (`entries`: `[{topic_id, person}]`) |
| `schedule_today` | ทุกคน | ข้อความของวันนี้ทุกสาขา (หรือ `branch`) ทุกภาษา (หรือ `lang`) |
| `save_topic` / `delete_topic` / `get_topic_texts` | รหัสกลาง | เพิ่ม/แก้/ลบหัวข้อ |
| `ai_translate` | รหัสกลาง | ให้ AI แปล (แค่แนะนำ ยังไม่บันทึก) |
| `translate_page` | รหัสกลาง | แปลข้อความบนหน้าเว็บ (+ หัวข้อ) ที่ยังไม่แปล แล้วบันทึก |
| `list_translations` / `save_translations` | รหัสกลาง | ดู/แก้คำแปล |
| `save_branch` / `delete_branch` | รหัสกลาง | เพิ่ม/แก้/ลบสาขา |
| `save_staff` | รหัสกลาง | ตั้งรายชื่อพนักงานของสาขา |
| `check_admin_pin` / `change_admin_pin` | รหัสกลาง | เช็ค/เปลี่ยนรหัสแอดมินกลาง |
| `import_schedule_from_sheet` | `admin_pin` ตัวที่อยู่ใน APP_STATE1 ของชีท | ดึงข้อมูลเดิมจากชีทเข้าสาขา |
